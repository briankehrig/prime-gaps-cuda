# format: <start(e12)>, <end(e12)>, <minGap>, [deviceIdx]
# if deviceIdx is not included, it will default to 0
# each line will only run if deviceIdx matches the command line argument to the python code
# this way, you can run multiple instances with different devices
#     without editing the worktodo.txt or settings.json files.
# E.g. you can have something like this:
# 22000000,22010000,0
# 22010000,22020000,1
# 22020000,22030000,0
# 22030000,22040000,1
# If you run two instances of the python wrapper, and give different device indexes as arguments,
# the instance that got a deviceIdx of 0 will only run the 1st and 3rd of those lines,
# and the one that got a 1 will run the 2nd and 4th lines.
